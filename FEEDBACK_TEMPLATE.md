# Web project feedback template

[简体中文](FEEDBACK_TEMPLATE.zh-CN.md) · [Sharing guide](SHARING_GUIDE.md)

Use this for a web tool, interactive page, portfolio, or demo. One report should describe one task or issue. A suggestion can use the same structure; explain the task it would help with.

---

**Project and version:** [Name, URL, version/date.]

**Task I tried:** [What you were trying to accomplish.]

**Steps:**

1. [Action.]
2. [Action.]
3. [Action.]

**Expected result:** [What you expected to see.]

**Actual result:** [What appeared or prevented the task.]

**How often it happens:** [Every time, sometimes, or not yet reproduced.]

**Environment, if relevant:** [Device, browser, and version you know.]

**Screenshot or extra detail, if useful:** [Attach only what helps explain the result.]

**Suggested change, optional:** [What would help, and why.]

---

Use sample data when reproducing a problem. Public reports should not contain credentials or another person's private information.

For this repository, [open an issue](https://github.com/sakuraladder/wuxianyuedu-creative-web-starters/issues/new) with a GitHub account and paste the completed report. The template itself does not send data or create an issue. For another project, use its creator's actual feedback channel.

After a fix, the maintainer can reply with the changed version/date, what was changed, and the result of repeating the reported task. Record checks still outstanding.
